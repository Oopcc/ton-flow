# TON Flow

Визуализатор кошельков **TON / Toncoin / Gram**: кто отправлял на адрес и кому отправлял он, в двух колонках вокруг центрального кошелька. Кроссплатформенно (macOS / Windows / Linux), на Tauri.

## Возможности
- **Потоки** — получено (слева) / отправлено (справа) по адресам: число переводов, сумма TON, комментарии, NFT, jetton'ы. Толщина линии = число переводов. Клик по адресу — перейти к его кошельку.
- **Транзакции** — лента с временем, суммой и комментариями.
- **Подарки TG**, **Юзернеймы**, **Номера**, **.ton домены** — NFT кошелька по вкладкам.
- **Jettons** — балансы токенов.
- Вход: адрес (raw / friendly) или `name.ton`.

Данные берутся из [TonAPI](https://tonapi.io). Без ключа ~1 запрос/сек; ключ из [tonconsole.com](https://tonconsole.com) вводится в поле «API key» (хранится локально).

> Вкладка «Подарки» определяется эвристикой (NFT с трейтами Model/Backdrop), «Юзернеймы»/«Номера» — по названию коллекции.

## Запуск
```bash
npm install
npx tauri icon app-icon.png   # один раз, генерирует иконки
npm run dev                   # нужен Rust: https://rustup.rs
```
Или просто откройте `src/index.html` в браузере.

## Релиз
```bash
git tag v0.1.0 && git push origin v0.1.0
```
GitHub Actions соберёт `.dmg` (universal), `.exe/.msi`, `.deb/.AppImage/.rpm` и выложит их в Releases.
